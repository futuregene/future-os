## 验证与局限

- Mobile：TypeScript、ESLint 与完整 Jest 套件。
- Desktop 后端：Rust 1.97.0 格式化、全 target Clippy（警告即错误），以及 GUI 与 headless 两种配置的完整测试。
- Android 与 iOS 生产 JS/Hermes bundle 均导出成功，包括 MathJax 的原生环境与 Metro 字体别名兼容性。
- 根式、分数、幂与矩阵的实际 SVG 输出均已渲染并目视检查，无缺字形或裁切。这**不是**真机截图测试。
- 未提供原测试手机、所安装的 APK/IPA 版本或 Office 阅读器配置。物理 Android/iOS 的打开/保存交接与行内数学基线/布局仍需真机验收；单元 mock 与 bundle 成功不能证明这些操作系统行为。

## 真机验收清单

1. 从会话文件和聊天链接打开生成的 Word/Excel 文件。在未安装阅读器时保存/分享；在安装兼容阅读器后打开。验证取消与中文文件名。
2. 使用同时含 `.hidden` 与普通文件的目录。切换两次；只有点文件的可见性应发生变化。
3. 手机连接时，先隐藏一个桌面模型，再全部隐藏，然后恢复一个。确认选择器跟随桌面端。重连后再重复一次。
4. 在桌面端更改当前对话的模型/思考等级。确认手机无需重开即更新；另一个对话中的更改不得影响它。
5. 在 Android/iOS 上检查行内根式与显示分数/矩阵，包括较大无障碍字号与窄屏。不支持的 TeX 必须仍以源码形式可见。
6. 流式回复期间输入第二份草稿。确认它挺过完成，且未经显式提交不会发送。
