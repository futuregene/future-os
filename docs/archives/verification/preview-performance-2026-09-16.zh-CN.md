# 预览性能：保留聊天与有界读取（2026-09-16）

> 本文是历史快照 [Preview performance: retained chat and bounded reads](./preview-performance-2026-09-16.md)（2026-09-16，跟进 PR #664）的忠实逐段中文翻译，保留原文结论、时间与 commit 边界；译文不是新的复核结论。

PR #664 的后续。本轮只改 Mobile；不改远程协议，也不取消模型生成。

## 改动

- 当文件面板、预览弹窗或下载弹窗遮住聊天时，保留既有对话/输入区子树。在被遮住期间忽略新的父级渲染快照，解除遮挡后安装最新的 children/callback。保留原生列表标识、展开行与草稿状态，而不是把它们卸载。
- 通过该 memo 边界传递呈现可见性，让已用时长与停止诊断定时器在被遮挡期间暂停。远程状态继续同步。无障碍隐藏保持在冻结子树之外并立即更新。
- 通过只读文件句柄读取文本预览，每次最多 64 KiB，每 256 KiB 让出一次。即使文件有 10 MiB，读取也不超过既有 2 MiB 预览上限。成功、取消与失败都关闭句柄。
- 有界读取不使用 Expo `File.slice()`：已安装的实现会先调用 `bytesSync()`，仍会加载整个文件。
- 不用 `TextDecoder` 的 fatal/stream 选项校验 UTF-8——移动端 `fast-text-encoding` 回退不支持它们。在截断边界上，宁可省略不完整的合法尾随码点，也不插入替换字符；拒绝非法的内部 UTF-8 与二进制控制字节。
- Markdown 文件预览改用有界 FlatList 渲染区块，而不是把所有区块挂进一个 ScrollView。大型预览（超过 128 Ki UTF-16 码元）绕过共享消息解析缓存，使其 AST 在关闭后可被回收。

## 验证

Mobile typecheck、ESLint 与全部 **99 个套件 / 1,399 个测试**本地通过。

新增的确定性回归负载：

| 负载 | 验证结果 |
|---|---|
| 500 次被遮挡的父级更新 | 无额外内容渲染；无卸载；本地展开状态保留；解除遮挡时安装最新快照 |
| 新聊天项到达时的文件面板 / 预览 / 下载浮层 | 同一 FlatList 实例保留；解除遮挡后可见新数据；文件面板的无障碍隐藏仍然生效 |
| 2,000 段 Markdown 文件 | 所有区块仍在 data 中，但 RN 测试渲染器最初只挂载 8 个文本块；大文件解析不全局缓存 |
| 上报 10 MiB 的文件大小 | 只请求/读取 2 MiB，单次最多 64 KiB，完成前另一个排队任务可运行，整文件 API 从未被调用 |
| 读取让出后取消 | 不再读取，只读句柄关闭 |
| UTF-8 / EOF / 解码器兼容 | 覆盖 CJK/emoji 边界处理、非法/过长/代理序列、意外 EOF，以及不支持 fatal/stream 的回退解码器 |

文件 I/O 测试使用插桩的原生句柄 mock。渲染测试使用 React 测试渲染器，而不是手机或 RN-Web。它们证明的是有界工作量、状态保留与正确性；**并不**证明磁盘吞吐、原生帧率或电池节省。上一轮的真实历史浏览器测量没有被当作本轮的测量复用。

## 剩余限制

完整的受限 Markdown 前缀仍需解析。单个巨大表格/代码块是一个列表项，内部不做虚拟化。完整下载与完整性校验未变；本轮只是避免随后整文件预览读取。应用内浮层打开期间，时间线投影/目录同步仍在继续。整体时间线缓存核算与射频/传输能量仍是独立工作。

原生滚动保留、模态切换、键盘行为、内存峰值与功耗仍待发布设备验证。
