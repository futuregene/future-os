- 桌面端：tsc、ESLint、**101 个文件 / 870 个测试**通过。

- 休眠/不受支持的生产者 API 与被反驳的断言在各账本中列明原因；不会被静默计为已修复的生产缺陷。
- 已发布目录：**158 个仅输出字段的新增**保留全部 3826 行的顺序/其他字段，并排除 **110 个经源码确认的非聊天模型**。[溯源](./model-output-provenance-20260911.json)记录数据来源；[432 个未匹配身份](./model-output-unmatched-20260911.json)保持显式未分类。
