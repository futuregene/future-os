## How the docs stay correct

- `docs/wiki/{en,zh}/Models.md` are generated by
  `make generate-models` (scripts/generate_models.py) — never hand-edit.
- The wiki pages are authored to the scope in
  [wiki-prompt.md](wiki-prompt.md): macOS + Windows app, no TUI page, no
  gRPC/port internals, CLI named `future`.
- The docs in this directory are verified against source; the verification
  working notes track every claim to a `file:line`.
