此样本与下方合成工作负载不同，不能直接计算跨样本优化百分比。

## B1a / B1b：上一版未发布分段实现

来源：原始验收 JSON 的 `earlierStorageSample` 与 `storage`。统一记录的候选来源为 `3f9e2208`，

| 样本 | 正文约量 | format 1 数据库＋WAL 字节 | format 2 数据库＋WAL 字节 | format 1 结束提交 µs | format 2 结束提交 µs |

| B1a 首次 | 1 MiB | 19,382,456 | 8,972,824 | 39,555 | 1,661 |
| B1a 首次 | 10 MiB | 200,795,664 | 21,868,544 | 60,283 | 1,633 |

首次样本与回归测试并行；最终样本在其余回归退出后执行。两组都保留，不挑选更漂亮的一组代替另一组。
每组是合成单样本；体积按批采样、包含 WAL，checkpoint 时机和文件复用会影响结果，未做历史压缩或 VACUUM。
直接 writer 批次和结束提交耗时，不等于 UI 帧耗时、整个运行时延或实时待提交积压。
原始 JSON 还保留行数、提交分布、数据库/WAL 分项、checkpoint 和并发读写观测，应一起参考。

## B2：紧凑变更的内存布局原型

仅在内存数据库中投影 B1c 的元数据；未改变个人数据库、未复制正文，也不是新实现的运行时测试。
原型保留原时间戳和未知 JSON，包含上下文定位、游标、计费及正文反向索引。

| 范围 | 当前布局 | 候选原型 |
|---|---:|---:|
| 元数据表及相关索引分配字节 | 921,600 | 385,024 |
| 对应分配量 | 900 KiB | 376 KiB |
| 变更条数 | 1730 | 1730 |
| 元数据语义还原 | 原始输入 | 1730 条全部一致 |

局部空间减少 58.2%；其中 1522 条使用直接范围，候选有 214 个上下文描述，扩展字段链接剩 70 条。
实验事件码和 SQL 不是冻结的生产契约。未实现的 RPC、恢复、权限、回收和迁移不能由此判为通过；
不包含正文、WAL、写入量、CPU/RSS、提交积压、UI 或磁盘故障测量。

## 后续 B3 的记录规则

- 使用独立的新结果文件，登记提交、目标布局/会话格式、设备/工具链、负载参数、页大小及构建模式。
- 同机同负载分别测 legacy、上一版保留基线和新实现；不让待发布代码承担上一版开发库升级。
- 记录 WAL/FULL/checkpoint、采样位置、并发干扰、重复次数、分位和最大值；同时测页占用与写入量。
- 原始输出和摘要对应，失败、回退和例外保留；不覆盖 B0/B1/B2，也不把局部比例外推到整个历史库。
- 缺失原始数据时明确标缺失；补测建立新记录，不改旧记录的数值。
- 实现后从冻结发布夹具重新验证迁移，报告单独关联 B3；上一版的迁移通过记录只是历史证据。
