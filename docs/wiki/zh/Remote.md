# 手机远程

FutureOS Mobile 支持 Android/iOS，用来控制桌面上的会话。工具在**桌面电脑**执行，
不是在手机沙箱里执行。请保持电脑唤醒、桌面应用运行，并让两台设备联网。

## 配对手机

1. 从对应平台的官方分发渠道安装手机端（Android 安装包，或渠道提供的 iOS TestFlight 邀请）。
2. 在桌面登录，打开 **Remote（远程）**，选择**配对并启动**。
3. 打开 FutureOS Mobile，授予相机权限并扫描桌面二维码；也可手动粘贴配对码。
4. 配对码**五分钟**内有效且**仅可使用一次**。过期后重新生成，不要分享或公开截图。
5. 在手机上选择已有桌面会话，或创建新会话。

生产版与测试版必须使用匹配的服务环境。其他环境签发的配对码会被拒绝；应使用匹配的
构建，不要修改配对码或端点来绕过检查。

## 可以做什么

查看流式回复、思考与工具活动；发送消息和附件；选择模型/思考级别；重命名会话；停止运行；
回应审批请求。支持格式的图片/文件可以预览和下载。重连可回补遗漏事件，但电脑休眠或离线时，
必须恢复可达后才能执行新任务。

Remote 控制相同的桌面会话并沿用其权限，配对不会自动开启审批或沙箱模式。
允许远程任务访问敏感文件前，请阅读 [[审批与沙箱|Sandbox]]。

## 断开与撤销访问

**断开**仅停止当前远程连接，不等同于撤销设备。手机不应再控制电脑时，使用**解除配对**；
之后再使用该手机需要新的配对码。手机丢失或交给他人时应撤销访问，同时保护桌面账户。

## 隐私与传输

命令、会话事件和请求的文件内容经过配置的 NATS 中继。手机使用每设备凭据、短期 JWT 和
刷新 token，秘密保存在平台安全存储中，连接要求 `wss://`。桌面到 NATS 的链路遵循部署
配置，不无条件强制 TLS。这不代表端到端加密，也不代表数据仅在本机处理。
只配对可信设备，并使用可信中继部署。

## 排障

- **相机权限被拒：**在手机系统设置里授权，或手动粘贴配对码。
- **配对码无效/过期：**生成新码，确认生产/测试版本环境匹配。
- **桌面离线：**确认电脑未休眠、应用运行、Remote 已连接。
- **重连/配对错误：**按显示的原因和 code 处理；过期或撤销的配对需要重新配对，短暂网络故障可重连。
- **待审批：**检查请求范围并明确批准或拒绝，不要仅为了消除安全提示而切换不受限模式。
