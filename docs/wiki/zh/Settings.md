# 设置

从窗口左下角进入设置：左栏折叠时是底部的**齿轮图标**，展开时在账户菜单里（点击头像和邮箱）。设置对话框左栏是导航，按用途分成五组：

| 分组 | 页面 |
|---|---|
| **应用** | 外观、快捷键 |
| **会话** | 权限、回复、存储 |
| **模型与技能** | 提供商、模型、技能 |
| **账号** | 账号、检查更新、关于 |
| **调试** | 重置（测试版构建还多 **Fusion** 与 **环境**，见文末） |

导航顶部有**搜索框**：输入设置名或页面名，结果会注明它属于哪一页；回车打开第一条，Esc 只清空输入。输入页名（如「存储」）得到的是那一页本身，不是同名的那一行。

## 先分清一件事：哪些只作用于这台机器

| | 存在哪里 | 手机能看到吗 |
|---|---|---|
| 外观（语言、明暗、配色、字号、模型输出展示）、快捷键、完成提示音 | 这台机器上的这个客户端 | 看不到，也改不了 |
| 权限、回复、存储 | 这台机器自己的设置 | 配对的手机会读到并修改 |

所以「只影响我看到的样子」的项在**应用**，「智能体怎么干活」的项在**会话**。完成提示音属于前者：它由这台机器播放，手机有自己的一套「任务完成提醒」。

## 应用

### 外观（本机偏好）

- **界面语言** —— 跟随系统、中文或 English；默认跟随系统。
- **界面外观** —— 浅色、深色或跟随系统外观。
- **配色主题** —— 14 套配色（FutureOS、Ayu、Catppuccin、Dracula、Everforest、Gruvbox、Kanagawa 等），每套都有浅色与深色两种形态，随上面的外观设置切换明暗。这一行只显示当前配色的色样，点**展开全部 14 套配色**才列出完整清单。
- **字体大小** —— 小、中、大、特大；只缩放文字，不改变布局。
- **模型输出展示** —— 回答结束后面板显示多少内容：
  - **默认**（出厂档位）—— 只保留最终回答，思考、工具调用和中间说明收起到回答上方的一行，随时可展开；生成过程中仍完整显示。
  - **详细** —— 保留完整过程：思考、工具调用和中间说明按发生顺序与正文一起显示。

  这是**这个客户端**怎么画对话，不是机器的属性：手机在**外观**页有同样的选择。

- **提示 → 完成提示音**（默认开启）—— 智能体跑完时播放提示音并吸引窗口注意力。它在这台机器上响，手机没有这一项。

### 快捷键

快捷键在应用内全局生效。页面提供：

- **搜索命令**按名称过滤；
- 按分组列出命令（最常用的在前），分组可以折起；你在 Vibe 面板里的那组默认收起，它们只在那面板打开时生效；
- 点一项开始录制新按键，单项可以**恢复默认**，也可以**全部恢复默认**；
- 底部列出**固定键**（Enter、Esc 等），它们由应用写死，不可改。

改完立刻生效，没有保存按钮。

## 会话

### 权限

**审批模式**决定 agent 在操作前询问到什么程度：

- **完全访问**（默认）—— 跳过所有审批，也不启用沙箱；命令以本机完整权限执行。
- **手动审批** —— 文件访问遵循审批规则；只读白名单命令直接放行，其余命令需批准，不启用 OS 沙箱。
- **沙箱保护** —— 命令在 macOS 沙箱、Linux Bubblewrap 或 Windows 写保护里运行，必要时请求批准；文件访问仍遵循路径规则，各平台保护范围不同。
- **自动审批** —— 在沙箱之上由一个模型审核器替你决定沙箱模式下本来会询问你的请求。它需要 OS 沙箱和已登录的 FutureOS 账号，两种缺失的回退不同：沙箱不可用时请求改走手动审批、设置保留；登出或凭据失效则把已保存的设置降级为**沙箱保护**，重新登录也不会自动恢复。

沙箱不可用或 Linux 只提供写保护时，这一页会多出一行说明原因。默认值、Linux 安装、诊断与限制见 [[审批与沙箱|Sandbox]]；批准卡片用法见 [[使用 FutureOS|Using-FutureOS]]。

### 回复

这一页的两项在任何客户端上都一样，描述的是回复本身：

- **选项卡**（默认关闭）—— 允许回复末尾带一张可勾选的选项卡。关闭时不显示卡片，也**不会在系统提示词里告诉智能体有这种格式**，所以没有回复会带卡；开启后，关闭期间看不了的历史卡片会重新显示。设计见[回复里的选项卡](../../design/choice-cards.zh-CN.md)。
- **首轮回答后自动生成标题**（默认开启）—— 仅在新会话的第 1 轮回答成功结束后生成并保存标题，后续回答不再触发，不压缩对话上下文。

### 存储

**会话自动归档**一节：

- **归档时自动清理运行日志**（默认开启）—— 保留聊天正文、命令标题和生成的文件，清理命令输出与运行回放；取消归档后仍可继续对话，已清理的运行日志无法恢复。
- **自动归档闲置会话**（默认关闭）—— 仅归档超过闲置天数的未置顶会话，运行中、等待审批和当前查看的会话会跳过；工作区本身不会自动归档。
- **闲置天数**（1–365，默认 30）—— 闲置指距离最后一次对话后一直没有新的消息或运行活动；查看、重命名不重新计时，取消归档后从恢复时重新计算。

**整理数据库**是这一页末尾的一次性维护动作，不是重置：它逐个对话升级旧格式、回收可清理的过程数据（命令输出、运行回放与快照）、压缩正文，最后回收文件空间。跑完给出整理前占用、整理后占用和已释放空间；进行中、格式异常或失败的对话会被跳过，可展开失败详情。聊天正文保留，不需要重启应用。

## 模型与技能

### 提供商

provider 就是你的模型来源。

**内置**里第一行是 **Future**，也就是你的 FutureOS 账号：这一行只显示登录状态与**更新模型列表**——登录与退出都在**账号**页，未登录时这里的按钮直接跳到那一页。列表里还有其他内置提供商（如 DeepSeek、OpenAI、Anthropic、Google 等），点**设置**填入或更新自己的 API key；用**更多供应商**展开完整列表。

**自定义**可以添加自己的 provider。点 **+ 添加自定义提供商**，填写：

- **名称** —— 显示名（可选）。
- **Provider ID** —— 唯一 id（小写字母、数字、`-`、`_`）。
- **API 类型** —— OpenAI Completions、OpenAI Responses 或 Anthropic。
- **Base URL** —— provider 的 API 地址（`http`/`https`）。
- **API Key**。
- **模型** —— 一个或多个模型 ID；每个模型还要填写显示名、必需的上下文窗口与最大输出 token，并可选填思考能力、模态和每百万 token 价格。

应用会校验字段并检查 provider ID 是否唯一。之后可以**编辑**或**移除**自定义 provider。

> provider 的 API key 与其他凭证分开保存。

### 模型

按 **provider 分组**列出所有可用模型：

- **搜索**按模型名或 provider 名过滤；分组标题可折起，也能一次显示或隐藏该 provider 的全部模型。
- **逐个切换模型的可见性** —— 隐藏的模型会从模型选择器里移除，让你的列表只保留常用的。

输入框里的模型选择器与这里同源，并显示每个模型来自哪个 provider。

### 技能

- **自动升级技能** —— 每次打开 App 时静默把已安装技能升级到最新版本。
- **智能技能推荐**（默认关闭）—— 发送消息时推荐至多一个你尚未安装的技能。

技能本身的安装、升级与卸载在左侧栏的**技能**页。见 [[技能|Skills]]。

## 账号

### 账号

显示已登录的 FutureOS 账号：状态、余额与**充值**，也是唯一能**登录**和**退出登录**的地方（退出前会二次确认）。余额用于抵扣平台上的模型调用费用，为 0 时新的任务无法运行。社区版使用自己的模型与密钥，不经过平台计费，因此不显示余额。

### 检查更新

检查是否有新版本的 FutureOS，并下载安装、重启生效。这一页显示**上次检查的时间**（缓存结果不会被当成刚刚查过），安装包不适用时给出手动下载入口。版本号本身在**关于**页，这里不再重复。如何应用更新见 [[安装 FutureOS|Installation]]。

### 关于

- 应用名称与**版本号**（唯一显示版本的地方），测试版构建还会带一个**测试版**徽章；
- 许可证（MIT）、官网、GitHub；
- 微信公众号卡片（二维码、复制公众号名、读一篇文章）——社区版不显示；
- 基于哪些开源软件构建。

## 调试（主要是测试版构建）

正式版构建里这一组只剩**重置**；**Fusion** 与 **环境** 只在测试版构建中出现。

### 重置

- **清空数据** —— 抹掉 FutureOS 的本地数据与临时工作区并重启应用：会话、后台程序和审查记录会被移除，登录状态和 provider 设置保留；不可撤销，执行前会二次确认。
- **写保护权限 → 重置写保护权限**（仅 Windows）—— 移除 FutureOS 为写保护添加的文件夹权限，不会删除文件；有任务正在运行时请等它结束再重置。

整理数据库不在这里：它不清空数据，已经移到**存储**页。

### 环境（仅测试版构建）

在**正式环境**与**测试环境**之间切换登录与接口地址；切换会清除当前登录并自动重启，需要在新环境重新登录。同一页还有**社区版**开关：开启后隐藏商业版功能（账号余额、Future 账号提供商等）。

### Fusion（仅测试版构建）

配置 `/fusion` 讨论：开启后可用 `/fusion` 发起多模型讨论，关闭不影响已经开始的讨论。主持人负责整理议题和总结，参与者选 2–5 个角色，每个角色独立选择模型与思考等级；同一个模型可以出现在多个角色上，并分别设置思考等级。

## 手机上

配对的手机有同名页面：**权限 / 回复 / 存储 / 模型 / 提供商 / 技能 / 定时任务设置**，写的都是那台桌面的设置；手机自己的偏好（外观、语言、微信公众号）在另一层。手机设置顶部也有搜索框，规则与桌面一致。
